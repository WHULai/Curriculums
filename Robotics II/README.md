# 《机器人学 II》期末复习册

> 魏崃

[阅读复习册 PDF](./main.pdf) · [LaTeX 入口](./main.tex) · [章节源码](./chapters)

沿用《机器人学》课程笔记的封面、目录、中文排版及 Definition / Example / Question / Note 样式。各章结合讲义讲解模型、公式和使用条件，配典型例题与自测。讲义配图在图注标明出处。

## 复习范围

按课后作业、讲义推导和计算例题确定复习优先级。建议先独立做控制作业，再按各章例题补齐计算和原理。现有材料中没有正式考试大纲。

| 章节 | 主要材料 | 重点 |
| --- | --- | --- |
| 1 驱动器 | 《2-Actuators-驱动器》 | 电机模型、转矩与转速、减速与惯量折算、电液气驱动比较 |
| 2 机器人传感技术 | 《第2章：机器人传感技术》 | 内外传感器、编码器、六维力、接近觉与触觉 |
| 3 图像形成 | 《第3章：图像形成》 | 视场、分辨率、镜头选型、针孔投影、畸变与标定 |
| 4 图像处理与特征提取 | 《第4章：图像处理与特征提取》 | 灰度与几何变换、滤波、形态学、分割、特征与分类 |
| 5 机器人控制 | 《第5章 机器人学-机器人的控制》及《控制部分 课后作业》 | 单关节与多关节控制、轨迹跟踪、逆动力学、视觉伺服 |
| 7 基于强化学习的机器人控制 | 《第七章-基于强化学习机器人控制路径》 | MDP、折扣回报、PPO 裁剪、动作模仿和模型预测 |

驱动器讲义单独编为第1章，其余章节沿用讲义编号。现有材料未见第6章讲义。控制作业精解紧随第5章，覆盖五道原题与所附的教材题 9.1、9.4、9.10、9.15、10.3。《机器人学：建模、控制与视觉》用于核对基础内容和教材题。

[控制作业 MATLAB 脚本](./scripts/control_homework.m) 可复现第1至4题的响应，使用 MATLAB 自带的 `ode45` 和绘图函数。

编码器专题和人形关节电机选型专题用于补充原理及实际约束。《世界模型、AGI 与具身智能》作为第7章末的拓展阅读，用于联系预测与滚动优化。品牌参数、视频演示、项目版本和训练跑分可按兴趣查阅原材料。

## 编译

在本目录运行以下命令，需安装包含 XeLaTeX、latexmk 和 Biber 的 TeX 发行版。讲义插图与重绘图已随源码收录。

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

版式源自 [Zaahir Ali 的 LaTeX 模板](https://www.overleaf.com/latex/templates/template/cwqbynvjjzbx)，沿用仓库中《机器人学》的改编。感谢课程教师的讲授及模板作者的分享。
