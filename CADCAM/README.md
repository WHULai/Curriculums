## 内容

- 第1至3章：CAD/CAE/CAM主线、计算机图形学、坐标与齐次变换、投影、裁剪、消隐、几何/拓扑/特征建模、装配与MBD。
- 第4至5章：Hermite、Bezier、B样条、NURBS、连续性、曲线求交与拟合，以及张量积曲面。
- 第6至7章：扫描采集、点云预处理、PCA法向、刚体配准与ICP、网格重建修复、曲面拟合，以及3D打印原理和工艺比较。
- 第8至9章：CAPP信息输入、派生式/创成式及专家系统，APT、刀位数据、后置处理、插补与制造误差。
- 附录A：讲义及独立作业图片的原题详解，共同题合并，差异题注明来源；附录B：跨章速查和综合自测。

各章以概念、推导、例题、适用条件、易错点和带答案自测组织，语言风格参考 Robotics 与 Robot Sensing Technology。正文复习示例与原作业分开标注。原讲义的个别符号、裁剪判断和英文拼写混排按推导核正，并在相关位置提示。

## 编译

需要 XeLaTeX、latexmk 和已安装的 **Source Han Serif SC**（常规及粗体）。在本目录执行：

```sh
./scripts/build.sh
```

中间文件写入 `tmp/build/`，成品更新到 `main.pdf`。不需要访问原始下载目录。

如需重新裁取讲义图片，使用具备 `pypdf` 的Python执行：

```sh
python3 scripts/extract_figure.py \
  --source '/原始资料/讲义.pdf' --page 11 \
  --box 0.1 0.2 0.9 0.85 --output img/figure.pdf
```

`--page` 从1开始，`--box` 顺序为左、上、右、下，采用0到1的页面相对坐标。每次裁剪后应渲染核对边界和清晰度。
